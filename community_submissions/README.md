# Community submissions

Each subdirectory is an immutable contribution package containing `submission.json` and
`note.md`. Start from [`how_to_contribute/submission_template`](../how_to_contribute/submission_template)
and follow the complete [contribution guide](../how_to_contribute/README.md).

Only explicit end-to-end leaderboard submissions enter the two-independent-auditor queue.
Standalone lemmas and research notes remain available without audit until a leaderboard proof
uses them.
